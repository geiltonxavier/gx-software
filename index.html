Inteligência artificial aplicada

Onde a IA entra no meu trabalho, e onde ela não entra

Não vendo IA como produto. Vendo prazo menor e menos bug. Ela acelera partes específicas do processo, e essas partes eu sei nomear.

  • Leitura de código legado

    Mapeio dependência, gambiarra e risco num projeto .NET Framework antigo em horas, não em semanas de leitura.

  • Teste de regressão a partir do bug

    Antes de corrigir, escrevo o teste que reproduz o problema. Depois corrijo. O bug não volta.

  • Correção e tradução de código

    Migração de versão, troca de biblioteca e tradução de SQL complexo, sempre com teste cobrindo antes e depois.

  • Documentação que sai do código

    README, runbook e descrição de arquitetura gerados do próprio repositório, para o próximo dev não começar do zero.

Código sugerido por IA passa pelo mesmo pipeline e pelos mesmos testes do resto. Nada chega em produção sem revisão minha.

// Compila, mas o status nunca é validado e a thread fica presa no I/O.
public Pedido Obter(int id)
{
    var resposta = _cliente
        .GetAsync($"/pedidos/{id}")
        .Result;                     // segura uma thread do pool

    var json = resposta.Content
        .ReadAsStringAsync()
        .Result;

    return JsonSerializer
        .Deserialize<Pedido>(json);  // CS8603
}
// Assíncrono de ponta a ponta, com status tratado e cancelamento.
public async Task<Pedido> ObterAsync(
    int id, CancellationToken ct)
{
    // sem barra inicial: preserva o /v1/ do BaseAddress
    using var resposta = await _cliente
        .GetAsync($"pedidos/{id}", ct);

    if (resposta.StatusCode == HttpStatusCode.NotFound)
        throw new PedidoNaoEncontradoException(id);

    resposta.EnsureSuccessStatusCode();

    return await resposta.Content
        .ReadFromJsonAsync<Pedido>(ct)
        ?? throw new InvalidOperationException(
               $"Corpo inválido para o pedido {id}.");
}

Caso técnico baseado em padrões reais. Eu compilei e executei antes de publicar, e o exemplo anterior não passava do build: CS1503, porque GetAsync devolve a resposta, não o corpo. Os dois problemas de compilação estão corrigidos aqui.
